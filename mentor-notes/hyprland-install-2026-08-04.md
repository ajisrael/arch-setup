## Hyprland install on Arch Linux

Started 2026-08-04. Mentoring session - guidance, not solved-for-you.
Starting point: fresh base Arch install, no display server/WM yet. New to Wayland and AUR.

### Facts confirmed from research
- Source: ArchWiki "Hyprland" page (raw wikitext, fetched 2026-08-04) and Hyprland's GitHub README (`~/examples/Hyprland`, cloned locally for reference).
- Package: `hyprland` (official repos, not AUR).
- Hard requirement: Polkit package installed, OR `seatd.service` started+enabled - without one of these Hyprland fails to start.
- NVIDIA: unsupported officially; if applicable, must follow the upstream NVIDIA-specific wiki page *before* first launch, or expect login failures/flashing windows/high CPU.
- VMware/VirtualBox: may need 3D acceleration enabled in the VM to run Hyprland properly.
- Config file: `~/.config/hypr/hyprland.lua` (Lua-based config since v0.55; auto-generated example on first run if missing; also viewable at `/usr/share/hypr/hyprland.lua`). Reloads automatically on save, or manually via `hyprctl reload`.
- Portals: `xdg-desktop-portal-hyprland` recommended for screen sharing/global shortcuts; doesn't include a file picker, so `xdg-desktop-portal-gtk` is commonly added alongside it.
- Starting the session: three options -
  1. Display manager (GDM/SDDM etc.) - unofficial but widely reported to work; the `hyprland` package ships desktop entries.
  2. From a getty via `start-hyprland` wrapper command (has crash recovery/safe mode; plain `Hyprland` binary is no longer recommended directly).
  3. Universal Wayland Session Manager (`uwsm`) - upstream no longer recommends this path for most users; flagged experimental/for advanced users.

### System up to date, GPU checked
- `pacman -Syu` run clean. Patched kernel (`linux` 7.1.5.arch1-2.1) is ahead of repo version - confirmed this is safe, plain `-Syu` never downgrades (see commands doc).
- GPU: Intel Iris Graphics 6100 (Broadwell-U), driver `i915` already bound. No NVIDIA-specific setup needed - the upstream NVIDIA caveat from research doesn't apply here.

### Installed and first launch successful
- Installed via pacman: `hyprland 0.56.1-3`, `polkit 127-3`.
- Chose bare-TTY start method over a display manager for the first attempt (simpler to reason about, matches "not officially supported via DM" caveat from research).
- Launched with `start-hyprland` (the recommended wrapper - has crash recovery/safe mode, unlike calling the raw `Hyprland` binary directly).
- First launch showed the expected "autogenerated config" warning banner, referencing `~/.config/hypr/hyprland.lua` - matches research: config auto-generates on first run if absent.
- Confirmed default keybind `SUPER+Q` opens `kitty` terminal. `SUPER` = the Windows/Meta/Command-labeled key.
